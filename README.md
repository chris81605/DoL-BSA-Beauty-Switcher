# DoL BSA Beauty Switcher v0.3.18

基於 BeautySelectorAddon（BSA）的多美化快速切換工具。

適合同時安裝多套 BSA 人模美化的環境，例如 **AU 美化、Goose 美化**等。設定完成後，可以直接在遊戲內快速切換不同的人物美化，並自動處理各美化所需的附屬模組。

## 使用方式

### 1. 管理美化包

在「管理美化包」中，勾選想要加入快速切換的人模美化。

建議只勾選完整的人模美化，例如：

- AU 美化
- Goose 美化
- 其他完整人物美化包

服裝、髮型、單獨部件或其他一般 BSA 模組通常不需要勾選。

### 2. 設定附屬美化包

如果某套美化還需要其他 BSA 模組配合使用，可以將它們設定為該美化的附屬包。

例如：

```text
AU 美化
├─ AU xxx 改臉
├─ AU xxx 服裝
├─ AU xxx 髮型
└─ AU xxx etc.
```

之後切換至 AU 美化時，這些附屬包也會一起啟用；切換至其他美化時則會一起停用。

一般只建議加入**以該美化為前置，或必須搭配該美化使用的模組**。

不確定的項目保持未勾選即可。

### 3. 切換美化

設定完成後，在「當前美化」中直接選擇想使用的人物美化即可。

例如：

```text
當前美化
├─ 關閉已管理的美化
├─ AU 美化
└─ Goose 美化
```

選擇其他美化時，模組會自動切換對應的主美化與附屬包。

選擇「關閉已管理的美化」則會關閉交由本模組管理的人物美化，恢復使用原版人物資源。

其他沒有交由本模組管理的 BSA 模組不受影響。

## 臉部素材相容回退

預設啟用。

當目前使用的美化缺少部分臉部素材時，模組會嘗試尋找可用的相容素材，降低切換不同人物美化後出現臉部部件缺失的情況。

如果使用的美化不需要此功能，也可以直接在「美化切換」中關閉。

## 更新日誌

### v0.3.18

- 模組正式更名為 **DoL BSA Beauty Switcher**。
- 完成多套 BSA 人模美化的快速切換、附屬包聯動與 Face fallback 整合。
- 重整遊戲內設定介面，改善大量 BSA Type 環境下的操作體驗。

### v0.3.8

- 加入附屬美化包管理。
- 每套主美化可指定需要一起啟用或停用的 BSA 模組。
- 未交由本模組管理的 BSA Type 保持原有狀態。

### v0.3.0

- 模組由 **Art Source Router** 轉型為基於 BeautySelectorAddon 的多美化管理工具。
- 可自行指定要管理的 BSA Type，並在多套人物美化之間互斥切換。
- Face fallback 從素材來源切換中獨立，作為可單獨啟用的相容功能。
- 不再以不同素材 root/source 作為主要的美化切換方式。

### v0.2.5

- 以 **Art Source Router** 為主要架構。
- 提供素材來源 routing 與 Face fallback。
- Face fallback 依序嘗試相容的臉部素材路徑，處理不同美化素材結構間的缺失。
